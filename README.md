# Self-Care + Baby Store — Premium Clean Cloudflare Pages

Mobile-first React/Vite storefront using the approved premium blush, cream, beige and soft-gold direction.

Business identity:
- Self-Care + Baby Store

The exact location, phone number and opening hours are intentionally left as updateable placeholders because the supplied project information did not establish a confirmed current contact record in this build.

The preview image is NOT used inside the website. Each section uses separate relevant baby/self-care imagery. The site includes a circular floating WhatsApp button.

Deploy:
npm install
npm run build
Cloudflare Pages build command: npm run build
Output directory: dist
